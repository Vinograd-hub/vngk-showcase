# V.N.G.K — Creative Digital Studio

Креативный шоукейс-сайт бренда **V.N.G.K**. Одностраничник в тёмно-синей минималистичной гамме с тёплым медным акцентом, плавными анимациями и адаптивной вёрсткой.

## Стек

- Чистый **HTML + CSS + JavaScript** (без сборки, без зависимостей)
- Шрифты: [Syne](https://fonts.google.com/specimen/Syne) (заголовки), [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) (текст), [Space Mono](https://fonts.google.com/specimen/Space+Mono) (лейблы)

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```
